    Administer this library with an AI agent

    No admin server — the whole library is managed from its GitHub repo.

    This catalogue, the source documents, the generated PDFs and the metadata all live in one GitHub repository. To add, edit or re-publish a policy you connect an AI coding agent — Claude Code or OpenAI Codex — to that repo and ask in plain language. It edits the registry, regenerates the PDFs and pushes; Cloudflare redeploys this site automatically.

    RepositoryBiomar-digital/copmapny-timeline

    ① Connect Claude Code

    • On the web: open claude.ai/code, authorise the GitHub app for Biomar-digital, pick the repo above and start a session on the branch above.
    • In the terminal: 
      npm install -g @anthropic-ai/claude-code
git clone https://github.com/Biomar-digital/copmapny-timeline
cd copmapny-timeline && git checkout claude/confident-curie-gudwtz
claude

    ② Or connect OpenAI Codex

    • On the web: open Codex, connect the same GitHub repo and branch.
    • In the terminal: 
      npm install -g @openai/codex
git clone https://github.com/Biomar-digital/copmapny-timeline
cd copmapny-timeline && git checkout claude/confident-curie-gudwtz
codex

    ③ Then just ask

    • "Add a new policy from this .docx — owner X, approver Y — and publish it."
    • "Publish Version 2 of the Diversity Policy from this updated .docx, with changelog notes '…'."
    • "Review the reader comments and PDF annotations and address each one in the next revision."
    • "Regenerate the Remuneration Policy without the approval pages."

    The agent edits policies/registry.json, runs python policy-formatter/tools/publish.py and pushes. Reader feedback it can read lives in policies/comments/ (per version) and policies/annotations/ (anchored to the exact quoted PDF text).
